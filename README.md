### 🧠 What I care about

- **Grounded answers.** Retrieval with citations, and the system admits it doesn't know instead of guessing.
- **Cheap first, LLM last.** Deterministic rules handle the easy 80%. The model only gets the hard cases.
- **Failing safely.** Guardrails, human-review gates, and services that fail closed.
- **Proof, not vibes.** Eval gates run before anything ships.
